# Fitness & Nutrition Assistant

A modern, sleek, and mobile-first fitness, workout, and nutrition tracking application developed for personal use.

## Features
* **Dashboard:** Daily calorie and macro tracking.
* **Workout Tracking:** Exercise and set management based on programs like Push, Pull, and Leg.
* **Nutrition / Water Tracking:** Meal-based calorie/macro logging and water intake tracking.
* **Progress:** Weight and body measurement history charts.
* **Settings:** Customization of personal goals and units.

## Technologies
* React + TypeScript + Vite
* Tailwind CSS
* Recharts
* Lucide React
